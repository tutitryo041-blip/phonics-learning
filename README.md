# カタカナ フォニックス

英単語を見て、**カタカナで読めるようになること**だけを目的にしたフォニックス学習アプリです。
英語の意味や文法は扱いません。ブラウザだけで動き、インターネット接続・登録・APIキーは不要です。

## 使い方

- `index.html` をブラウザで開くだけで使えます（GitHub Pages などに置いても動きます）。
- 毎日「学習を始める」を押すと、その日の30問が出題されます。英単語を見て、カタカナ（ひらがなでもOK）で入力してください。選択式はありません。

## 仕組み

| 項目 | 内容 |
| --- | --- |
| 1日の問題数 | 30問 |
| 合格ライン | その日の正答率 90％以上 → 次のルールへ |
| 90％未満 | 同じルールを、まだ出していない別の単語でもう一度 |
| 70％未満 | 同じルールを、短くやさしい単語中心でもう一度 |
| 2回続けてミス1問以下 | 次のルールとその次のルールを同じ日にまとめて進める（30日より速く進める） |
| 毎日の問題の中身 | 新しいルール ＋ 前回間違えた単語（必ず全部・最大15問） ＋ ランダム復習（間違えた回数が多い単語ほど出やすい） |
| 全ルール終了後 | 苦手な単語中心の復習 |

ルールは 25 個（短母音 → x・qu・wh → sh・ch・th → ck・ng・nk → 子音のつながり → マジック e → ee・ea → ai・ay → oa・ow → ar・or → er・ir・ur → oo → ou・ow → oi・oy）。
1日1ルールの速さなら約25日、繰り返しが入るとそれより長くなり、30日前後が目安です。

## 正解の判定

- 単語ごとに正解のカタカナを登録しています（`js/curriculum.js`）。
- 同じ音の自然な書き方の違いは正解にします：`cat` → キャット／キャト、`cake` → ケイク／ケーク。
- 発音の違いは区別します：`ship`（シップ）と `sheep`（シープ）、`hop`（ホップ）と `hope`（ホウプ）、`cut`（カット）と `cute`（キュート）。
  - 長い o（hope・boat・snow）は「オウ」。「オー」は or の音（fork フォーク）として区別します。
- ひらがな・半角カナ・前後の空白は自動で整えてから判定します。

## 学習履歴

- 日付・正答率・間違えた単語・単語ごとの成績を、ブラウザ（localStorage）に保存します。
- 次の回の内容は、この履歴（前回の正答率とミス単語）から自動で決まります。
- 「学習履歴」画面から JSON で書き出し／読み込みができます（端末を変えるとき・バックアップ用）。
  ブラウザのデータを消すと履歴も消えるので、定期的に書き出しておくことをおすすめします。

## 開発

```
npm test   # 判定と出題ロジックのテスト（Node.js 20 以上、依存なし）
```

- `js/curriculum.js` ルールの説明と単語・正解候補
- `js/judge.js` 入力の正規化と正誤判定
- `js/planner.js` その日の出題と、次の回の内容の決定
- `js/storage.js` 履歴の保存
- `js/app.js` 画面
